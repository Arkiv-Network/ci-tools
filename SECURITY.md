# Security policy

Report a vulnerability in these actions or scripts privately, through GitHub's private vulnerability
reporting: <https://github.com/Arkiv-Network/ci-tools/security/advisories/new>. Do not open a public
issue for it.

Include the affected action or script and the commit SHA, what an attacker can do, and the steps or
the workflow that reproduce it.

A finding that `sbom-scan` reports in an image is a vulnerability in that image, not in this
repository; report it to whoever ships the image.
